# Lacrosse head terminology and model reference

## Names used in this study

| Term | Meaning |
| --- | --- |
| Head | The molded frame attached to the shaft. A **strung head** also includes the pocket and its strings. |
| Face / face shape | The head's front outline and opening. |
| Scoop | The curved top edge used to pick up ground balls. It has a ground-facing lip and a pocket-facing surface. |
| Top-string holes | The slots through the scoop used to attach the mesh. Six holes do not mean six separate strings. |
| Top string | The cord securing the top mesh row to the scoop. |
| Scoop recess / relief panel | A shallow depression, not a through-hole. The reference shows two panels, each surrounding three top-string slots. |
| Sidewall | Either structural side of the plastic head. Not the same thing as the sidewall string. |
| Sidewall string | The cord attaching the mesh edge to the sidewall holes. |
| Sidewall holes | The smaller stringing openings along each sidewall rail. |
| Rails | The long borders of a sidewall. ECD uses “bottom rail” for the lower/pocket-side rail; this does not mean the throat platform. |
| Struts / sidewall braces | The structural webs joining the rails around the large sidewall windows. |
| Throat | The narrow base of the head where it meets the shaft. |
| Socket / shaft receiver | The fitting that accepts the shaft through its underside. The internal bore stays open; the rear wall does not. |
| Receiver rim | The continuous lower edge around the shaft entry. This is not the shaft's butt end. |
| Rear throat wall | The plastic behind the shaft bore. It connects the receiver to the throat bridge. |
| Screw hole / screw pilot hole | A small opening through the receiver wall for the head-to-shaft fastening screw. Not a stringing hole. |
| Throat bridge / ball-stop platform | Our modeling name for the solid base joining the sidewalls and supporting the stop pad and bottom-string holes. Manufacturer wording varies. |
| Ball stop / stop pad | The insert on the inside base of the head. On the Mirage 3.0 reference, it is the rectangular “MIRAGE 3.0” piece—not the triangular crab badge on the front. |
| Bottom-string holes / throat holes | The openings at the pocket's base through which the bottom string passes. |
| Bottom string | The cord securing the lower mesh to the head; its adjustment affects pocket depth. |
| Mesh | The woven sheet used to form the pocket. Diamond count names a row pattern, not the total opening count. |
| Pocket | The shaped netting that receives and holds the ball. |
| Channel | The central path in the pocket that guides the ball toward release. |
| Shooting strings / shooters | The laces or cords across the upper pocket that affect release. These are distinct from the top string. |
| Shaft | The handle attached to the head. Archived; not part of the current study. |
| Butt end / end cap | The cap at the opposite end of the shaft. It is not the ball stop or part of the head. |

## Current corrections

1. Keep the scoop's six top-string slots open, but give the scoop a continuous rear surface and real thickness.
2. Add the throat bridge. It must connect the sidewalls, not leave an empty gap behind the front badge.
3. Put the rectangular ball stop on the bridge and provide bottom-string holes behind it.
4. Preserve the central head opening, sidewall windows, front throat cutouts, and underside shaft entry.
5. Keep the accepted ball stop unchanged. Refine the four bottom slots using the higher-resolution close-up.
6. Remove artificial rear scoop ridges. Retain a shallow front recess, not a hollow scoop.
7. Join the throat into one receiver with a closed rear wall. Do not combine a separate circular lip with the traced base.

The current single rear screw pilot hole is provisional. The available product photographs do not show its exact placement or establish the screw-hole count. Do not label this detail manufacturer-verified.

The mesh is not displayed. Its separate flat study has one repeated six-sided cell shape. A fitted pocket can deform under tension; the earlier row-dependent resizing was not a valid simulation of that behavior.
